# gganime: Animate 'ggplot2' Plots with 'Anime.js'

Renders 'ggplot2' plots written with 'gganimate' syntax as animated
Scalable Vector Graphics (SVG) drawn in the browser by the 'Anime.js'
JavaScript library (<https://animejs.com>), through the 'animejs'
package. The result is a single self-contained, resolution-independent
'htmlwidget' with one timeline over the plot's elements.
